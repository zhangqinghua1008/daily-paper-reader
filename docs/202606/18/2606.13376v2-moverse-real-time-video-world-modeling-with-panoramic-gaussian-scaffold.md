## 摘要
我们提出MoVerse，一种实时视频世界模型，能够从单张窄视场图像构建可交互导航的场景。该任务具有挑战性，因为输入仅观察到环境的一小部分，而交互式漫游需要完整的周围世界、持久的几何结构、可控的相机运动以及时序一致的高保真观测。MoVerse通过将世界构建与观测渲染分离来解决这一问题。它首先利用拓扑感知扩散将输入扩展为重力对齐的360°全景，在三维推理前填补缺失的视场。然后，使用全景几何感知残差预测将全景提升为持久的三维高斯支架，生成致密且可直接渲染的空间记忆。最后，一个以高斯为条件的视频渲染器根据用户指定的相机轨迹，将支架渲染结果转换为逼真的视频。为使该渲染器适用于交互场景，我们训练了一个双向扩散教师模型以实现高质量条件渲染，并将其蒸馏为因果自回归学生模型以实现有界延迟流式传输。这一设计结合了显式三维表示的可控性和长程一致性以及生成式视频模型的感知质量。MoVerse在单个NVIDIA RTX 4090 GPU上以约8 FPS支持实时场景漫游，展示了从单张图像构建世界并输出交互式视频的实用途径。

## Abstract
We present MoVerse, a real-time video world model that creates an interactively navigable scene from a single narrow-field-of-view image. This setting is challenging because the input observes only a small fraction of the environment, while interactive roaming requires a complete surrounding world, persistent geometry, controllable camera motion, and temporally coherent high-fidelity observations. MoVerse addresses this problem by separating world construction from observation rendering. It first expands the input into a gravity-aligned 360$^\circ$ panorama with topology-aware diffusion, closing the missing field of view before 3D reasoning. It then lifts the panorama into a persistent 3D Gaussian scaffold using panoramic geometry-aware residual prediction, yielding a dense and directly renderable spatial memory. Finally, a Gaussian-conditioned video renderer translates scaffold renderings along user-specified camera trajectories into photorealistic video. To make this renderer practical for interaction, we train a bidirectional diffusion teacher for high-quality conditional rendering and distill it into a causal autoregressive student for bounded-latency streaming. This design combines the controllability and long-range consistency of explicit 3D representations with the perceptual quality of generative video models. MoVerse supports real-time scene roaming at 8~FPS on a single NVIDIA RTX~4090 GPU, demonstrating a practical path toward single-image world creation with interactive video output.

## 1. 核心问题与研究动机
- **任务定义**：从单张窄视场（NFOV）图像构建一个可以实时交互、自由导航的三维世界，并输出时序一致的高保真视频。
- **核心矛盾**：
  - 输入仅捕获场景的一小部分，而交互需要 360° 完整的周边环境。
  - 要求同时满足：可控的相机运动、持久的几何一致性、逼真的实时渲染质量。
- **现有方法局限**：
  - **显式 3D 方法**（点云、网格、3DGS）：提供持久空间记忆与精准相机控制，但从单图重建时会出现空洞、浮动物或感知质量低下。
  - **隐式视频/世界模型**（注意窗口、循环状态）：视觉效果好，但长程几何不稳定，场景容易漂移、身份变化。
  - **混合方法**：几何锚点太稀疏或生成式渲染器太昂贵、双向，不适合实时交互。
- **本文目标**：设计一种兼具显式 3D 可控性与生成式视频画质的系统，并具备实时流式能力。

## 2. 方法论：三阶段世界构建与渲染
核心思想：将**世界构建**（离线）与**观测渲染**（在线）分离，利用全景高斯支架存储持久空间记忆，由蒸馏的因果渲染器进行实时视频生成。

### 阶段 I：全景生成（从 I 到 P）
- **目标**：将输入的 NFOV 图像扩展为重力对齐的 360° 等距柱状投影（ERP）全景图。
- **关键技术**：
  - **可微自动水平校正**：估计密集对应场，经刚体变换瓶颈（软 argmin）去除俯仰和翻滚，将图像映射到重力对齐的正则化全景空间。
  - **拓扑感知全景补全**：使用圆形潜在编码，使卷积填充在水平方向循环闭合；引入水平循环移位等变扩散，通过移位一致性损失（`L_shift`）保证无缝。
  - **训练数据**：Horizon360 数据集，将原始全景图规范化到真正的水平线，并以输入视角为中心进行偏航偏移，避免周期性边界问题。
- **损失函数**：`L_stage1 = L_LDM + λ_shift L_shift + λ_flow L_flow`，其中 `L_flow` 使用平滑 L1 监督对应场。

### 阶段 II：高斯场景生成（从 P 到 G）
- **目标**：将全景图提升为持久、可直接渲染的 3D 高斯支架 G。
- **初始化**：
  - 从全景深度图 D 出发，通过球面反投影获得高斯中心 μ_k = D_k d(θ_k, ϕ_k)。
  - 纬度感知缩放：初始尺度 s_k ∝ D_k cos ϕ_k，补偿 ERP 随纬度变化的面积扭曲。
- **残差预测**：
  - 使用预训练视觉 backbone 提取多尺度特征，与 RGB+逆深度拼接后解码，再通过轻量预测头 h_ψ 输出残差。
  - 位置残差在角度-逆深度空间定义：(Δθ, Δϕ, Δz)，更新后重新投影，确保与 ERP 几何和水平闭环一致。
- **属性合成**：中心、尺度、四元数、颜色、不透明度均以残差形式更新，输出为标准 3DGS 资产。
- **训练目标**：
  - `L_tgt`：渲染视图与真实视图的 L1 + LPIPS + SSIM。
  - 源视角重建损失、逆深度损失（`L_depth`）、位置残差正则（`L_Δ`）。
  - 总损失 `L_GS = L_tgt + λ_src L_src + λ_depth L_depth + λ_Δ L_Δ`。

### 阶段 III：高斯条件视频渲染（从 \hat{V}_{1:T} 到 V_{1:T}）
- **目标**：将支架沿用户轨迹渲染成 φ 流，再转换为高保真、时序连贯的视频。
- **双向教师模型**：
  - 基于 Wan2.1-T2V-1.3B（流匹配扩散 Transformer）。
  - 条件方式：噪声目标潜变量 z_t 与高斯渲染潜变量 c 拼接，并共享旋转位置编码（RoPE），使条件成为密集对齐的渲染引导。
  - 损失：`L_teacher = E||v_θ([z_t∥c], τ, t) - (ϵ - z)||^2`，仅在目标 token 上计算。
- **因果学生模型（流式渲染）**：
  - 为实时交互将双向模型蒸馏为因果自回归模型，每次生成一个潜变量块（对应 4 帧）。
  - 蒸馏策略：Self Forcing + DMD（分布匹配蒸馏），并结合 RAVEN 使梯度流过 KV 缓存。
  - 推理时使用两阶段去噪调度、MemRoPE 风格局部 KV 缓存（1 个沉没帧 + 滑动窗口），替换标准解码器为 TAEHV 以加速。
- **训练数据混合**：
  1. 真实视频 + 几何代理渲染（破洞、缺失区域）—— 训练修复相机平移造成的缺失。
  2. 稀疏关键帧→高斯支架渲染—— 暴露浮动物、透明物等 3DGS 特有瑕疵。
  3. 全景→高斯支架渲染—— 最接近部署时状态。
