## 摘要
尽管事件相机在水下SLAM中展现出巨大潜力，但现有基于时间表面(TS)的方法在水下部署时高度不可靠。相机速度的波动严重降低TS成像质量，而宽立体基线与重复的水下纹理引发关键的匹配失败，频繁导致系统失效。为克服这些挑战，我们开发了首个高精度事件驱动水下立体SLAM系统。基于结构张量相干性和梯度，我们设计了一种结构感知TS度量，以量化TS结构信息密度。通过将最优TS生成解耦为基于系统初始化的两个独立阶段，贝叶斯优化(BO)在初始化前序贯预测最优先验TS，而在跟踪阶段我们设定异步在线局部搜索方法定期实时获取合适TS。我们利用先验视差保证精确数据关联，并采用“最新观测优先”三角化机制实现稳定三角化。作为这些解决方案的基准和社区资源，我们还贡献了UWE，首个高质量真实水下事件数据集，包含变化的相机运动、复杂纹理和不同轨迹特征。在公开数据集和UWE上的广泛评估显示，所提出的SLAM系统与最先进的事件驱动方法相比具有竞争力的精度性能。代码和数据将开源。

## Abstract
While event cameras offer immense potential for underwater SLAM, existing Time Surface (TS)-based methods prove highly unreliable when deployed underwater. Fluctuating camera velocities severely degrade TS imaging quality, while wide stereo baselines and repetitive underwater textures induce critical matching failures, frequently triggering system failure. To overcome these challenges, we develop the first high-accuracy event-based underwater stereo SLAM system. A structure-aware metric for TS is designed based on structure tensor coherence and gradients to quantitatively evaluate TS structural information density. By decoupling the optimal TS generation into two distinct stages based on system initialization, Bayesian Optimization(BO) first predicts an optimal prior TS sequentially before initialization while we set an asynchronous online local searching method periodically to obtain appropriate TS in real-time during the tracking stage. We use the prior disparity to guarantee precise data association and "latest-observation-first'' triangulation mechanism to realize stable triangulation. As a benchmark for these solutions and a resource for the community, we also contribute UWE, the first high-quality real-world underwater event dataset containing variable camera motions, complex textures and different trajectory features. Extensive evaluations on public datasets and UWE show the competitive accuracy performance of the proposed SLAM system compared to the state-of-the-art event-based method. The code and data will be open-sourced.

## 2. 方法论

### 核心思想
系统构建于ESIO框架之上，核心在于**自适应的TS生成与鲁棒的立体追踪**。将TS的时间衰减系数`τ`视为“曝光时间”，通过**结构感知信息度量**来量化TS质量，并设计**双阶段自适应优化策略**来实时调整`τ`。同时，引入**先验视差引导**和**最新观测优先三角化**来解决匹配难题。

### 关键技术细节与算法流程

1.  **结构感知TS质量度量**
    -   **问题**：传统图像信息熵不适用于TS，因为其会随`τ`单调递增，无法体现最优质量。
    -   **解决方案**：发现空间梯度和结构张量相干性在最优TS时会出现明确峰值，因此基于二者设计度量。
    -   **公式说明**：
        -   计算TS图像`Iτ`的结构张量`Jρ(x)`，并求其特征值`λ1 ≥ λ2 ≥ 0`。
        -   定义相干性`C(x) = ((λ1 - λ2) / (λ1 + λ2))^2`，衡量边缘锐度。高相干性对应清晰边缘。
        -   结合梯度幅值`G(x) = ||∇Iτ||`，定义单像素结构质量分数`Q(x) = C(x) · G(x)`。
        -   对整个TS的有效像素区域`R`计算全局结构感知分数 `M(τ) = Σ(Q(x)) / Σ(Iτ(x))`，表示**单位能量的结构信息密度**。`M`值越大，TS质量越好。

2.  **双阶段自适应时间衰减系数优化**
    -   **问题**：频繁更新`τ`在速度骤变（如转弯时）会产生噪声，尤其在初始化阶段危害大，且引入延时。
    -   **解决方案**：将`τ`优化解耦为两个阶段，分别用不同方法。
    -   **阶段一：初始化前序贯贝叶斯优化**
        -   系统启动时，利用贝叶斯优化（BO）以最小评估次数，黑箱式寻找全局最优`τ*`。利用高斯过程（GP）作为代理模型，并通过期望改进（EI）采集函数平衡探索与利用。
        -   获得的`τ`作为固定值，用于后续的SfM初始化，保证数值稳定性。
    -   **阶段二：跟踪中异步在线局部搜索与平滑**
        -   初始化后，在一个独立线程中周期性执行离散局部搜索。在当前活跃的`τ`周围生成候选集，并选择使`M`分数最高的候选值。
        -   为防止LK光流因`τ`剧变违反光度一致性假设，使用**自适应一阶低通滤波器**平滑更新`τ`：`τ_{k+1} = (1 - α_eff)τ_k + α_eff τ̂_k`。步长`α_eff`会根据质量改善情况动态调整，避免噪声引起的震荡。

3.  **鲁棒立体追踪与三角化**
    -   **自适应视差引导立体匹配**：
        -   **问题**：大视差和重复纹理下LK光流直接搜索容易陷入局部最优或失败。
        -   **解决方案**：利用历史匹配信息提供的先验视差，约束搜索起点。
        -   **流程**：对当前帧的特征点，若其ID存在于前一帧的匹配集，则复用其历史视差作为先验`d̂_{k,i}`；否则使用所有历史视差的全局中值。然后在LK光流开始前，先用此先验偏移右图搜索起点（`p̃_{r,i} = p_{l,i} - d̂_{k,i}`），再进行亚像素优化，最后通过前向-后向一致性检查剔除误匹配。
    -   **最新观测优先三角化**：
        -   **问题**：传统ESIO的特征深度初始化依赖其“首次被观测到”时的立体匹配，水下环境常导致首次匹配失败，进而特征被永久丢弃，造成特征枯竭。
        -   **解决方案**：对滑动窗口内持续跟踪的特征，反向遍历其历史轨迹，找到“最近一次成功的立体匹配”，并用其进行SVD线性三角化。通过这种方式“复活”了因初期匹配失败而未被初始化的有效特征点，大幅增加稳定三角化的特征数量。
