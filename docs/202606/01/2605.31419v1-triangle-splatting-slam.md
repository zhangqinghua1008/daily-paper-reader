## 摘要
我们提出一种密集的RGB-D SLAM系统，使用可微三角形作为三维地图表示。尽管三维高斯泼溅已成为新视角合成的主流方法，但三角形仍是传统渲染硬件、游戏引擎以及需要显式几何（如仿真、碰撞检测和编辑）的下游任务的标准图元。最近的离线方法已经表明，通过在一组已知位姿的图像上进行德劳内三角剖分，可以将非结构化的“三角片集”优化为照片级逼真的网格。基于这一认识，我们提出首个采用三角泼溅的密集SLAM系统，通过对三角片集进行在线可微渲染来同时执行跟踪与建图。该地图可通过受限德劳内三角剖分即时转换为连接网格，从而支持网格变形和碰撞检测等新在线功能。在Replica和TUM-RGBD数据集上，我们的系统在三维几何方面优于基线方法，相机跟踪精度相当，并且能够实现在线的基于网格的场景编辑。

## Abstract
We present a dense RGB-D SLAM system using differentiable triangles as the 3D map representation. While 3D Gaussian Splatting has emerged as the leading method for novel-view synthesis, triangles remain the standard primitive for traditional rendering hardware, game engines, and downstream tasks requiring explicit geometry such as simulation, collision, and editing. Recent offline methods have demonstrated that an unstructured 'triangle soup' can be optimised into a photorealistic mesh via Delaunay triangulation across a set of posed images. Building upon this insight, we present the first dense SLAM system to employ Triangle Splatting to perform both tracking and mapping through online differentiable rendering of a triangle soup. The map can be converted into a connected mesh on-the-fly via restricted Delaunay triangulation, enabling new online capabilities such as mesh deformation and collision checking. On Replica and TUM-RGBD, our system outperforms baselines on 3D geometry, matches the camera-tracking accuracy, and enables online mesh-based scene editing.

## 1. 论文的核心问题与整体含义

- 现有稠密视觉SLAM系统在追求照片级真实感渲染的同时，难以兼顾**显式的、可高效编辑和物理仿真的几何表示**。三维高斯泼溅（3DGS）虽渲染质量高，但其体积性导致几何提取不直接，生成的网格与深度估计不一致，难以用于碰撞检测、网格变形等实时交互任务。
- 三角形网格是计算机图形学、游戏引擎和工业仿真的标准表示，具有显式表面、自适应精度和成熟硬件加速的优点。但SLAM中维护网格拓扑的一体性十分困难，因此传统方法常将网格作为二级产品，主地图多用体素、SDF、面元或高斯元表示。
- 最近离线方法表明，通过德劳内三角剖分可将“三角片集”（triangle soup）优化为照片级网格，无需中间融合或后处理，但这一思想尚未被引入**在线SLAM**。
- 本文核心意义：**首次将可微三角形直接作为SLAM的唯一地图表示**，统一了跟踪、建图与网格生成，在线产生具备显式连接拓扑的网格，从而支持实时场景编辑等新功能。

## 2. 论文提出的方法论

### 2.1 核心思想
- 用一组可微三角形（顶点带颜色、不透明度）组成“三角片集”作为地图。通过对三角形投影进行可微光栅化，可从当前估计的地图渲染彩色图和深度图，并与传感器观测比较，优化相机位姿和地图顶点。
- 需要连接网格时，对当前三角片集运行**受限德劳内三角剖分**，实时获得拓扑正确的网格，使网格变形、碰撞检测成为可能。

### 2.2 关键技术与公式

#### 2.2.1 可微光栅化
- 基于Mesh Splatting与Triangle Splatting，定义三角形的2D有符号距离场\(\phi(p)=\max_{i} L_i(p)\)，并用窗口函数 \(I(p) = \text{ReLU}(\frac{\phi(p)}{\phi(s)})^{\sigma}\) 描述像素影响。
- 颜色累积公式（6）：按深度排序的Alpha混合，其中面不透明度 \(o_{F_m} = \frac13(o_i+o_j+o_k)\)（取均值代替最小值，以便梯度传播到所有顶点）。

#### 2.2.2 解析相机位姿雅可比
- 推导**解析雅可比**替代自动微分，大幅减少跟踪计算量：
  \[
  \frac{D \mathbf{v}_C}{D T_{CW}} = [\mathbf{I}_3,\ -[\mathbf{v}_C]_\times]
  \]
  并在CUDA核的后向传播中直接计算。

#### 2.2.3 跟踪与建图架构
- **跟踪**：最小化光度误差（L1 + D-SSIM）和深度L1损失，用解析雅可比优化帧位姿 \(T_{CW}\)。
- **关键帧选取**：基于共视性，计算当前帧与上一关键帧可见三角形的交并比，低于阈值则新建关键帧。
- **建图**：选取若干关键帧（最多共视的4帧+2随机帧+最新关键帧），每帧迭代30次，联合优化关键帧位姿与地图参数。
  - 光度损失：与跟踪相同。
  - 几何监督：利用传感器深度图计算法向 \(\bar{\mathbf{N}}\)，与渲染法向求余弦距离；深度L1损失。
  - 等边正则化：惩罚三角形内角与60°的偏差，避免退化细长三角。
- **三角形增删**：
  - 初始创建：新关键帧时从RGB-D反投影并生成等边三角形，半径由最近邻距离决定，方向用传感器法向初始化。
  - 致密化：对投影面积超过阈值的三角形进行**分裂**（边缘中点插入，1→4），原始三角形移除。
  - 修剪：移除平均顶点不透明度低于阈值的三角形，或投影面积过大的三角形（避免模糊或未充分覆盖）。

#### 2.2.4 网格化
- 在线时对三角片集运行**受限德劳内三角剖分**，得到即时可用网格，并可选择性修剪被所有关键帧遮挡的面，提高几何质量。

## 6. 论文的主要结论与发现

- **首次成功将可微三角片集用于在线SLAM**，实现跟踪和建图统一于单一显式表示。
- 在Replica数据集上，位姿精度与最佳基线（MonoGS-2D*）相当（ATE 0.34 cm vs 0.24 cm），并显著优于基于网格或体的方法。
- **三维几何精度大幅领先**：用本方法渲染深度图进行TSDF融合获得最低平均Chamfer距离（0.95 cm），修剪德劳内网格（1.14 cm）也优于所有基线的融合结果（如2DGS 1.36 cm）。
- 网格生成效率：德劳内比高精度TSDF融合快约两倍，且可增量更新。
- 本方法首次在SLAM中实现在线网格变形和场景编辑，展示了三角形表示面向交互任务的潜力。
- 系统对真实环境（TUM）鲁棒，对户外大规模场景也有初步通用性（借助单目深度估计）。

## 7. 优点

- **表示统一**：一个三角形表示同时满足照片级渲染、精确几何、快速网格生成，且与图形学管线直接兼容。
- **几何精度高**：得益于顶点直接参与深度/法向监督，渲染深度与最终网格严格一致，避免其他高斯方法中密度提取的不匹配。
- **实时网格能力**：德劳内三角剖分支持在线交互编辑，无需全量离线重建。
- **解析雅可比**：自行推导并实现高效的位姿梯度，显著提升跟踪速度。
- **策略丰富**：等边正则化、窗口致密/修剪、平均不透明度设计等均有针对性改进。
- **评估扎实**：对TSDF和德劳内双通道网格质量进行了全面定量，并分析时间-质量权衡。

## 8. 不足与局限

- **位姿精度略低于最先进的方法**：在Replica上，MonoGS-2D* ATE更低（0.24 vs 0.34），说明三角形表示对运动模糊、重复纹理的鲁棒性可能尚不及高斯元。
- **实时性受限于单线程实现**：当前FPS仅约0.5~2，离30fps实时要求有较大差距，文中也指出可通过多进程和共轭梯度加速。
- **网格拓扑质量**：德劳内网格仍可能出现自相交、非流形面，缺少进一步拓扑正则化，可能影响物理仿真等严格应用。
- **实验覆盖**：主实验集中在小场景（Replica）和受控室内序列（TUM），大范围、长时段的漂移和闭环能力未深入检验。户外实验仅作定性展示，未报告定量指标。
- **对深度传感器的依赖**：本文为RGB-D SLAM，对纯单目输入的扩展仅初步尝试，依赖外部单目深度估计。
- **效率与几何质量权衡**：文中指出最精确的几何来自TSDF融合深度图，然而实时网格（德劳内）的精度次之，仍是一种折衷。
- **未见大规模严格统计检验**：多数结果为单次运行，未报告多次运行的平均和方差，可能影响结论的统计显著性。
