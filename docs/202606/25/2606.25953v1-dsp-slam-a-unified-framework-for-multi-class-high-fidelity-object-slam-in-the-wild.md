## 摘要
现有的物体感知SLAM系统不得不在实时性能、多类别支持以及生成高保真、语义连贯的物体模型之间做出权衡。为了解决这一权衡，我们提出了DSP-SLAM++，它扩展了DSP-SLAM框架，采用异步建图流水线以实现实时性能，并针对单目鱼眼-LiDAR套件进行了专门的传感器融合调整。实验表明，我们的系统能够为多个物体类别生成精细、几何完整的形状，同时通过将最大物体处理延迟比最先进的基线降低多达70%，消除了严重的建图线程瓶颈，从而在具有挑战性的25 Hz多类别数据集上实现了稳健的实时性能。这项工作通过使高保真、多类别物体SLAM能够在搭载常见鱼眼-LiDAR传感器配置的平台上运行，使其在自动驾驶和机器人操控等现实应用中更加实用。开源代码可在以下地址获取：[github.com/AUBVRL/DSP-SLAMpp]。

## Abstract
Existing object-aware SLAM systems force a trade-off between real-time performance, multi-class support, and the generation of high-fidelity, semantically coherent object models. To address this trade-off, we present DSP-SLAM++, which extends the DSP-SLAM framework with an asynchronous mapping pipeline for real-time performance and dedicated sensor fusion adaptations for a monocular fisheye-LiDAR suite. Experiments demonstrate that our system generates fine-grained, geometrically-complete shapes for multiple object classes while eliminating severe mapping thread bottlenecks by reducing maximum object processing latency by up to 70\% compared to the state-of-the-art baseline, enabling robust, real-time performance on a challenging 25 Hz multi-class datasets. This work makes high-fidelity, multi-class object SLAM more practical for real-world applications like autonomous driving and robotic manipulation by enabling its use on platforms with common fisheye-LiDAR sensor setups. The open-source code is available at: [github.com/AUBVRL/DSP-SLAMpp].

### 论文核心问题与整体含义
现有物体感知 SLAM 系统面临实时性、多类别支持、高保真语义物体模型三者之间的根本性权衡。传统方法使用立方体或椭球等简单几何体，计算高效但丢失精细形状；基于隐式形状先验的 DSP-SLAM 虽能重建高保真网格，却被限制为单类对象且计算代价高昂；新近的 3D 高斯抛雪球方法虽渲染快，却缺乏实例级物体理解。同时，实际自动驾驶平台常采用鱼眼相机与 LiDAR 传感器，引发镜头畸变校正与尺度模糊等额外挑战。该论文旨在填补这一空白，提出一个统一的、在真实场景中可实时运行的多类别高保真物体 SLAM 系统。

### 方法论
DSP-SLAM++ 以原始 DSP-SLAM 为基础，通过三大核心改造实现目标：
- **多类别检测与类感知关联**  
  使用 YOLO 进行 2D 实例分割，PointPillars 进行 3D 检测。通过**全局贪心二分匹配**将 2D 掩膜与 3D 点云关联：对同一类别的检测对计算投影内点占比，构建评分矩阵，迭代选取最高分并互斥行/列，解决多类嵌套掩膜引起的歧义。地图关联引入**类条件搜索半径** \( r_c = \sqrt{l_c^2 + w_c^2} \)（基于类别平均尺寸），避免大物体漏配和小物体误配。  
- **类特定形状重建**  
  采用**模块化多解码器架构**，为每类物体独立预训练一个 DeepSDF 解码器。运行时根据语义标签动态选择对应解码器，优化物体位姿 \( \mathbf{T}_{co} \) 与形状隐编码 \( \mathbf{z}_c \)，避免单解码器的跨类干扰，并便于扩展新类别。  
- **异步重建流水线**  
  将耗时的 DeepSDF 优化与网格提取从本地建图线程解耦。本地建图线程仅创建边界盒占位符即时插入地图，将重建任务置入线程安全队列；由两个工作线程池后台处理，完成后异步更新地图。检测任务优先于重建，避免重建阻塞跟踪。  
- **鱼眼-LiDAR 深度融合**  
  采用 **2D 特征矫正策略**：将稀疏 ORB 特征点通过 Kannala-Brandt 模型矫正到虚拟针孔坐标系，再关联投影后的 LiDAR 点云深度，避免对整个点云施加畸变。掩膜投影时，仅提取掩膜轮廓点矫正，重建多边形，实现高效精确的 2D‑3D 对齐。

### 主要结论与发现
- DSP-SLAM++ 在 25 Hz 实时运行条件下成功生成多类高保真物体地图，最大物体处理延迟较同步基线降低 70%，消除了建图线程严重滞后和局部 BA 跳帧问题。
- 异步流水线与类条件关联机制使系统在面对多类拥挤场景时仍能保持稳健跟踪与正确关联。
- 鱼眼‑LiDAR 融合策略通过低计算开销的特征矫正与掩膜轮廓矫正，使系统适应主流车载传感器配置，保持了轨迹精度。

### 优点
- **架构解耦**：异步设计从根本上解决隐式重建的计算瓶颈，使建模复杂物体不再阻碍实时跟踪与地图优化。
- **高可扩展性**：模块化类特定解码器可便捷增加新物体类别，无需重新训练整个网络。
- **实用传感器适配**：针对鱼眼‑LiDAR 的轻量融合方案，让高保真物体 SLAM 更易部署于现有自动驾驶平台。
- **开源代码**：承诺开源，利于社区复现与后续研究。

### 不足与局限
- **点云质量依赖**：重建细节高度依赖 LiDAR 点云密度，对远处或被严重遮挡的物体（尤其行人等细薄/关节体）重建效果下降。
- **检测器瓶颈**：系统性能与上游 YOLO 和 PointPillars 检测可靠性紧耦合，极端场景下可能出现漏检或误检传导。
- **动态环境支持有限**：面向静态物体建图，且主要处理刚性物体，未集成物体追踪与运动预测，动态场景适应力不足。
- **LiDAR 依赖**：目前必须依赖 LiDAR 提供深度，限制了在仅相机平台上的应用。
- **对比局限**：仅与 DSP-SLAM 直接对比，未与其他物体 SLAM 范式（如基于立方体、四元数或 3DGS 的方法）进行定量横评。
