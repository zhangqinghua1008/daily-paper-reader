## 摘要
逐场景三维高斯泼溅（3DGS）能实现高保真渲染，但实际的机器人和AR场景捕捉流程通常依赖外部几何初始化（如运动恢复结构点云或深度估计），在现场部署中这可能缓慢且不可靠。我们提出了ACEsplat，一个快速逐场景优化框架，仅从RGB图像和相机位姿重建三维高斯表示，无需外部三维先验（如预计算的SfM模型或监督深度图）。ACEsplat采用两阶段流程：(1) 自监督场景坐标回归（SCR）模块在4–5分钟内构建内部几何先验；(2) 轻量级高斯初始化头融合SCR特征和坐标先验，随后进行逐场景3DGS优化。在静态视图渲染上，ACEsplat在Wayspots上使用实时SLAM位姿达到29.11 dB PSNR，在Cambridge Landmarks上使用SfM优化位姿达到33.20 dB。在RealEstate10K稀疏视图新视角合成中，它在具有挑战性的双视图设置下取得了有竞争力的图像保真度。ACEsplat在单个GPU上于15–25分钟内完成场景特定的SCR建图和3DGS重建，使其成为适用于机器人和混合现实应用中快速场景搭建的实用RGB+位姿解决方案。

## Abstract
Per-scene 3D Gaussian Splatting (3DGS) enables high-fidelity rendering, but practical robotic and AR scene capture pipelines often depend on external geometric initialization (e.g., SfM point clouds or depth estimates), which can be slow and brittle in on-site deployment. We present ACEsplat, a fast per-scene optimization framework that reconstructs 3D Gaussian representations from RGB images and camera poses only, without requiring external 3D priors (e.g., precomputed SfM models or supervised depth maps). ACEsplat uses a two-stage pipeline: (1) a self-supervised scene coordinate regression (SCR) module builds an internal geometry prior within 4--5 minutes; (2) SCR features and coordinate priors are fused by a lightweight Gaussian initialization head, followed by per-scene 3DGS optimization. On static-view rendering, ACEsplat achieves 29.11 dB PSNR on Wayspots with real-time SLAM poses and 33.20 dB on Cambridge Landmarks with SfM-refined poses. On RealEstate10K sparse-view novel view synthesis, it achieves competitive image fidelity under a challenging 2-view setting. ACEsplat completes scene-specific SCR mapping and 3DGS reconstruction within 15--25 minutes on a single GPU, making it a practical RGB+pose-only solution for rapid scene setup in robotics and mixed-reality applications.

### 方法论
ACEsplat 采用两阶段流程，将自监督场景坐标回归（SCR）与 3DGS 优化无缝衔接。

- **第一阶段：自监督 SCR 构建内部几何先验**  
  使用 Accelerated Coordinate Encoding（ACE）作为 SCR 骨干，通过重投影几何损失自监督训练，预测像素级场景坐标。训练无需深度真值，仅需 RGB 与已知位姿。  
  - 对图像像素 x，网络预测场景坐标 z = F_θ(x)。  
  - 优化目标为 DSAC\* 风格的鲁棒重投影误差，带有 curriculum 的 inlier 阈值。  
  - 输出：坐标先验图 P_i 与有效性掩码 M_i，只保留通过几何验证的像素。

- **第二阶段：SCR 先验驱动的 3DGS 初始化与优化**  
  1. **密集特征上采样适配器**：将低分辨率 SCR 特征通过双线性插值与卷积上采样至图像分辨率，得到密集特征图 F_i。  
  2. **高斯属性初始化头**：拼接 F_i 与 P_i，经轻量全卷积头预测高斯的不透明度 α、外观参数 A（球谐系数）、形状参数 Ψ；高斯中心直接用 P_i 初始化。  
     - 视为像素对齐预测：对有效像素 (u,v)，μ = P_i(u,v)，其余属性由头输出。  
  3. **场景级合并与生命周期优化**：合并所有视图的高斯集，然后进行标准 3DGS 优化（MSE+SSIM 损失），配合自适应密度控制（剪枝、分裂、不透明度重置），将过度完整的初始化压缩为紧凑表示。  
  4. **任务适配**：  
     - 静态视图渲染：单视图初始化，单视图监督。  
     - 稀疏视图新视角合成：双视图初始化，用保留视图评估。

### 主要结论与发现
- **ACEsplat 成功去除了外部几何先验依赖**，用自监督 SCR 快速生成内部几何锚点，使得 3DGS 初始化稳定，最终渲染质量有竞争力。  
- **在静态视图上**，Wayspots 平均 29.11 dB（SLAM 噪声位姿下），Cambridge Landmarks 平均 33.20 dB（SfM 精修位姿），且性价比优于 SfM+3DGS 流程。  
- **在极端双视图稀疏合成上**，ACEsplat 达 26.11 dB，超越 pixelNeRF、GPNR 等，接近 DepthSplat（27.47 dB）但无需深度监督与大规模预训练，且场景优化仅需 20 分钟。  
- **SCR 的多视图一致性几何约束**优于单目深度先验（20.23 dB vs 26.11 dB），像素对齐的 SCR 特征也远比 PointNet 特征有效。  
- **实时性**：单 GPU 15–25 分钟即可完成全流程，适合现场部署。

### 优点
- **无外部先验**：仅需 RGB 和位姿，避免了 SfM 或深度图的脆弱性。  
- **快速适应**：SCR 阶段在数分钟内生成场景特定几何先验，整体重建耗时短，适合机器人、AR 等时效场景。  
- **鲁棒性**：对噪声 SLAM 位姿有一定容忍度，稀疏视图下仍保持结构一致性。  
- **多视图一致性**：重投影损失天然迫使坐标跨视图一致，优于单目深度估计的尺度歧义。  
- **方法精巧**：重用 SCR 特征，轻量上采样与全卷积初始化头，设计简约。  
- **实验详尽**：覆盖三个不同特性数据集，多重消融，负责任地比较了计算资源，且提供了机器人现场演示。

### 不足与局限
- **弱纹理/反射区域性能下降**：SCR 依赖光度线索，在纹理缺失、高光处定位精度低，渲染质量随之下降（如 Wayspots “lawn” “statue” 场景）。后续优化虽可补偿，但难以完全恢复。  
- **稀疏视图下球谐函数过拟合**：文中承认在 2 视图设置下未充分研究球谐系数阶数调度，可能仍有颜色漂移风险。  
- **与无位姿/联合优化方法的公平对比缺失**：仅提及了 COLMAP-free 3DGS、NoPoSplat 等，未做受控实验，无法直接说明在位姿未知时的优势。  
- **密集特征上采样适配器的独立开销**：论文指出未单独报告其延迟与内存占用，对极低算力设备的影响未量化。  
- **场景规模限制**：测试集中于中小型场景，极端大规模（如城市级）的性能与用时尚未验证。  
- **依赖已知位姿**：若位姿估计本身失效（例如纯旋转或快速运动），则 SCR 训练无法启动，无 Fail‑safe 机制。
