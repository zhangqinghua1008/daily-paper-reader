## 摘要
低光新视角合成具有挑战性，因为暗光多视图图像含有噪声、弱结构细节和压缩的动态范围。最近的三维高斯溅射（3DGS）方法通过生成伪真值（pseudo-GT）图像作为监督目标来解决这些挑战，当没有配对的正常光照参考时。现有的伪真值方法对所有像素应用均匀线性增益，这会使亮区剪切而暗区增强不足，限制了重建质量。我们观察到，在二维低光增强中早已建立的非线性色调映射，尚未在三维重建的伪真值生成中得到探索。因此，我们提出了一个场景自适应的非线性色调曲线框架，用非线性替代方案取代线性伪真值。该框架引入了基于百分位数的归一化以实现场景无关的曲线应用，一个场景自适应偏移量用于自动黑电平调整，以及两条互补曲线：自适应SoftExp（ASE），一条有界指数曲线，和自适应Poly3（AP3），一条数据驱动的三次多项式。该模块只改变伪真值计算，而保持3DGS主干不变。在涵盖21个场景的三个基准上的实验表明，两条曲线都一致优于线性基线，在LOM上PSNR提升高达+4.34 dB，在RealX3D上提升高达+3.25 dB。尽管数学形式不同，两条曲线达到了相似的性能，表明改进与曲线无关。代码可在https://github.com/lvmingzhe/adaptiveToneCurve获取。

## Abstract
Low-light novel view synthesis is challenging because dark multi-view images contain noise, weak structural detail, and compressed dynamic range. Recent 3D Gaussian Splatting (3DGS) methods address these challenges by generating pseudo ground-truth (pseudo-GT) images as supervision targets when paired normal-light references are unavailable. Existing pseudo-GT methods apply a uniform linear gain to all pixels, which clips bright regions while providing insufficient enhancement in dark regions, limiting reconstruction quality. We observe that nonlinear tone mappings, long established in 2D low-light enhancement, have not been explored for pseudo-GT generation in 3D reconstruction. Accordingly, we propose a scene-adaptive nonlinear tone-curve framework that replaces linear pseudo-GT with nonlinear alternatives. The framework introduces percentile-based normalisation for scene-agnostic curve application, a scene-adaptive offset for automatic black-level adjustment, and two complementary curves: Adaptive SoftExp (ASE), a bounded exponential curve, and Adaptive Poly3 (AP3), a data-driven cubic polynomial. The module changes only the pseudo-GT computation and leaves the 3DGS backbone unchanged. Experiments on three benchmarks covering 21 scenes show that both curves consistently outperform the linear baseline with PSNR improvements up to +4.34 dB on LOM and +3.25 dB on RealX3D. Both curves achieve similar performance despite their different mathematical forms, suggesting the improvement is curve-agnostic. Code is available at https://github.com/lvmingzhe/adaptiveToneCurve

## 2. 方法论
**核心思想**：构建一个**场景自适应的非线性色调曲线框架**，替代LITA‑GS中原本的均匀线性伪真值计算。该框架包含三个组件：
1.  **百分位归一化**（Percentile‑based Normalisation）  
    *   用输入图像亮度的第90百分位数 `p90` 进行归一化：`t = I_low / p90`，替代对异常值敏感的均值归一化，使曲线作用与绝对曝光水平解耦。
2.  **场景自适应偏移**（Scene‑Adaptive Offset）  
    *   定义阴影紧凑比：`r = p10 / p90`。  
    *   自适应黑电平提升量：`δ₀ = α·(1 - r)^β`，其中 `α = 0.12`、`β = 2.5` 全局固定。`r` 越小（阴影越严重），`δ₀` 越大，以增强暗部细节；`r` 大时则减小偏移，防止过亮。  
    *   该机制使同一个偏移公式能跨不同场景自动适配。
3.  **两条互补的非线性曲线**  
    *   **自适应 SoftExp (ASE)**：`f_ASE(x) = δ₀ + (1 - δ₀)·(1 - e^{-g·t})`，其中 `g = g₀ + c·Ÿ`，`g₀ = 1.0`，`c` 为数据集级亮度增益。指数曲线天然有界，平滑且具备物理可解释性。  
    *   **自适应 Poly3 (AP3)**：基于数据驱动的三次多项式 `p(t) = 0.072t³ - 0.438t² + 0.995t`（系数在单个场景上拟合后冻结），输出经过 `f_AP3(x) = clamp(δ₀ + p(t)^b, 0, 1)`，其中 `b = 1 + c·Ÿ`。近线性斜率保留中亮部排序，三次项压缩高光。  
    *   两条曲线均集成亮度自适应增益 `c·Ÿ`：当原始图像均值 `Ÿ` 较高时自动增加曲线陡度，补偿归一化后拉伸不足的问题。

**集成方式**：模块仅替换训练循环中的伪真值计算，LITA‑GS 的 3D 高斯属性、光栅化器、渐进去噪模块及所有损失函数均完全不变。每次迭代额外开销 <0.5 ms（相比约50 ms的光栅化可忽略）。

## 6. 主要结论与发现
*   **非线性映射是主驱动力**：无论在真实低光还是合成变曝光场景，替换线性伪GT为非线性色调曲线均能一致提升 PSNR、SSIM 和 LPIPS（LOM 上最高 +4.34 dB，RealX3D 上最高 +3.25 dB）。ASE 和 AP3 尽管数学形式差异显著，性能却相近（多数场景差距 <1 dB），证明改进具有**曲线无关性**。
*   **场景自适应偏移至关重要**：固定的黑电平提升量会严重损害某些场景（如 `bike`），而基于百分位统计的自适应偏移能自动为每个场景提供接近最优的偏移值。
*   **亮度自适应增益有效**：通过引入与图像平均亮度挂钩的动态增益，克服了固定增益曲线在中等暗度场景下增强不足的缺陷。
*   **配置统一且简单**：全局偏移参数 `α=0.12, β=2.5` 可跨所有基准保持不变，唯一需要按数据集调整的仅为亮度增益系数 `c`。

## 7. 优点
*   **模块化与即插即用**：仅修改伪真值计算，无需改动网络结构、损失函数或训练流程，易于集成进现有低光 3DGS 方法。
*   **原理清晰且双重验证**：通过两条设计原理不同的曲线（物理驱动的指数曲线 vs 数据驱动的多项式）共同验证了非线性映射本身的优越性，结论可信度高。
*   **自适应性强**：通过百分位归一化和场景自适应偏移，避免了繁重的逐场景超参调优，一个全局公式适配差异巨大的场景。
*   **无损于效率**：计算开销极低（<0.5 ms/迭代），几乎不影响训练速度。
*   **实验扎实**：涵盖 21 个场景、大量基线、系统消融和 22 种曲线的搜索，对分布重塑效应的解释增强了对方法的理解。

## 8. 不足与局限
*   **AP3 系数的泛化风险**：三次多项式系数仅在单个场景（`BlueHawaii`）上拟合得到并冻结，虽然在 20 个额外场景上表现良好，但对类型差异极大的场景的最优性未获保证。
*   **仍需数据集级调参**：亮度自适应增益系数 `c` 需要根据数据集曝光条件手动选择（`c>0` 用于持续欠曝数据集，`c=0` 用于变曝光数据集），尚未实现完全自动化。
*   **低迭代次数下的结构/感知指标退化**：在 MipNeRF360‑varying 上，5K 迭代预算下 SSIM 和 LPIPS 相对于线性基线出现退化，需要 15K 迭代才能恢复，其在低预算场景的鲁棒性有待提升。
*   **种子与统计显著性**：MipNeRF360‑varying 实验仅基于单种子（`s=10`）汇报，未提供多种子下的均值和方差，结论的统计稳健性稍弱。
*   **应用场景限定**：论文仅在 LITA‑GS 这一特定 3DGS 框架上验证，对于其他低光 NVS 方法（如基于 NeRF 或不同增强策略的模型）的泛化能力未做讨论。
