## 摘要
室内视觉重定位在新兴的空间与具身人工智能应用中发挥着关键作用。然而，先前的研究主要集中于低层级视觉方案，难以感知场景语义与组成，这限制了可解释性与适用性。本文探讨了如何将场景中丰富的对象信息（包括语义、布局和几何）组织成结构化的地图表示，从而独占地利用对象单元来驱动相机重定位任务。为此，我们提出了OpenReLoc，这是一个旨在提供场景理解与精确位姿估计能力的相机重定位系统。借助近期的基础模型，我们首先引入了一种多模态机制，融合开放词汇语义知识以实现高效的2D-3D对象匹配。此外，我们设计了面向对象的参考帧作为位置先验，并配以基于Distance-IoU（DIOU）的参考帧选择策略，使其能够扩展到可缩放的场景中。同时，为确保稳定而精确的位姿优化，我们还提出了一种由对象形状引导的双路径二维迭代最近像素损失。实验结果表明，OpenReLoc在多种数据集上均取得了优越的重定位召回率与精度。我们的源代码将在论文接收后发布。

## Abstract
Indoor visual relocalization plays a critical role in emerging spatial and embodied AI applications. However, prior research was predominantly devoted to low-level vision schemes, struggling to perceive scene semantics and compositions, which limits both interpretability and applicability. In this paper, we explore the issue of how to organize rich object information in a scene, including semantics, layout, and geometry, into a structured map representation, thereby utilizing object units exclusively to drive the camera relocalization task. To this end, we propose OpenReLoc, a camera relocalization system designed to provide scene understanding and accurate pose estimation capabilities. Leveraging recent foundation models, we first introduce a multi-modal mechanism to integrate open-vocabulary semantic knowledge for effective 2D-3D object matching. Additionally, we design object-oriented reference frames as position priors, paired with a reference frame selection strategy based on the Distance-IoU (DIOU), enabling extension to scalable scenes. Moreover, to ensure stable and accurate pose optimization, we also propose a dual-path 2D Iterative Closest Pixel loss guided by object shape. Experimental results demonstrate that OpenReLoc achieves superior relocalization recall and accuracy across various datasets. Our source code will be released upon acceptance.

## 2. 论文提出的方法论

**整体框架**：系统分为三个阶段——对象导向建图、地标关联、重定位。  

### 2.1 对象导向建图 (Object-oriented Mapping)
- **实例分割与地图构建**  
  - 利用 TSDF-Fusion 与 2D 分割的多视图一致性，将 2D 掩码提升为 3D 实例点云 `Oil = (Pi, B3di, Ci)`。  
- **参考帧分布**  
  - 设计面向对象的参考帧 `K = {(i, B2di)}`，仅记录可观测对象 ID 及其 2D 边界框，而非完整 RGB 图像，大幅减少存储。  
  - 新增参考帧依据：新对象出现或某对象可见面积超过之前最大值的两倍。  
- **多视图对象描述子**  
  - 对每个实例，选取多视图中可见度最高的 k 个裁剪块，经由 CLIP 视觉编码与平均池化得到多视图特征 `f3d`。  
  - 该描述子具备开放词汇语义，可识别未见类别。  
- **无效对象过滤**  
  - 剔除在大量参考帧中出现（如墙壁、地板）的通用物体，避免干扰地标关联与场景图。  
- **场景图提取**  
  - 构建全局场景图 `G(V|E)`，节点为对象，边为最近邻或 3D 边界框相交的对象对。

### 2.2 地标关联 (Landmark Association)
- **开放词汇匹配**  
  - 对查询图像，检测 2D 对象区域并提取 CLIP 视觉特征 `f2d_vision`。  
  - 仅保留特征方差大（判别性好）的对象进行匹配。  
  - 利用 LLM 代理为每个独特对象生成文本描述（只提供查询图像和分割出的对象区域），得到 `f2d_text`。  
  - 基于余弦相似度分别获得 Top-3 视觉候选和文本候选。两者一致时直接接受；否则进入候选集 `U`。  
- **子图匹配**  
  - 对不确定的候选集，构建查询对象的局部 2D 子图，并从全局图中提取候选 3D 子图（BFS 深度 η=1）。  
  - 将子图相似性度量为线性求和分配问题（LSAP），最大化匹配总得分，以确定最终地标关联 `L`。

### 2.3 重定位 (Relocalization)
- **粗位姿先验（Coarse Pose Prior）**  
  - 选择与查询图像共享最多匹配地标的参考帧子集。  
  - 计算 Distance-IoU (DIOU) 指标，综合考虑框的重叠度和中心距离，选出最相似的参考帧提供初始位姿。  
- **精细位姿优化（Refined Pose Optimization）**  
  - 提出双路径 2D 迭代最近像素损失 (`L_icp`)：  
    - 前向：将 3D 对象点云投影到当前位姿 `pi`，计算投影像素到目标掩码 `mi` 的最近像素距离；  
    - 后向：计算目标掩码像素到投影像素的最近距离；  
    - 对双向距离应用 Huber 核，并求和所有匹配对象。  
  - 该损失利用对象整体形状进行对齐，而非仅中心点，增强稀疏对应下的优化稳定性。

公式示意（文内未要求重现，用文字描述）：  
- 前向/后向损失：`L_f = 1/N_pi ∑ H(‖ p_i^n - ψ(p_i^n, m_i) ‖_2, δ)`，反向类似，总损失为所有对象双向损失的均值。

## 6. 主要结论与发现

- OpenReLoc 在 **所有数据集和所有阈值** 下均显著优于现有对象级方法（GoReloc），成功率提升 5–10 倍，同时精度（MTE/MRE）也大幅领先。  
- 与强特征点方法（PixLoc、MS-Transformer）相比，OpenReLoc 在召回率上占优，尤其在大场景和光照变化下，其语义稳定性发挥关键作用；虽然 PixLoc 精度略高，但需要的地图储存体积比 OpenReLoc 大 10 倍以上。  
- 提出的三种创新组件——多模态开放词汇匹配、基于 DIOU 的参考帧检索、双路径 2D ICP 损失——均对系统性能有重要贡献。  
- 对象级表示天然对光照变化、物体位移等具有较强的鲁棒性，通过自适应异常物体掩码可进一步应对动态物体。

## 8. 不足与局限

- **极端重复对象处理较弱**：场景图中子图匹配在大量相同物体（如数百把相同的椅子）时仍可能混淆。  
- **效率瓶颈**：依赖外部闭源 LLM（GPT）进行语义描述，在线 API 延迟高，占单帧运行时间的 80%，当前难以满足实时需求。  
- **有限动态场景验证**：仅模拟了少量物体的位移，未测试大规模连续动态变化。  
- **仿真到现实的泛化**：合成数据集上表现优秀，但实际场景的传感器噪声、复杂光照等因素可能增加难度，缺乏更多真实复杂场景的验证。  
- **其他地图构建依赖**：建图过程依赖 TSDF-Fusion 和 2D 分割质量，若前端分割失败，可能影响地图与重定位性能。  
- **未与学习型重定位方法**（如场景坐标回归）进行详细对比，虽然部分 APRs 作为基线，但代表性有限。  
- **仅部署在单个高端 GPU**，报告的资源使用情况不够详尽（如内存、显存占用）。
